# 智库随行：Note 4 安卓蓝牙中转

## 1.3.1：手动更新连接地址

设备连接 → 更新连接地址 → 粘贴电脑智库“设备管理”页显示的远程地址 → 验证并更新。服务器必须接受已有配对设备凭据，HTTPS 证书、响应格式与设备身份校验通过后才替换地址；失败保留原地址，不重新配对、不重发录音。没有固定查询入口，手机在外不能从失效的旧地址自动获取新地址。

Docker 远程通道启动后，由容器内部一次性程序在 120 秒预算内等待地址就绪，原子保存至 `media/voice-connection/current.json` 后退出；设备管理页可刷新和复制。Windows 无常驻地址更新程序、启动项或弹窗；容器保存地址不调用手机 ADB。失败保留上一份文件，界面提供保存时间，须留意时间是否对应本次启动。

## 1.3.0：电脑连接与自动同步

- 任务中心显示电脑知识库连接状态、最近成功同步时间；蓝牙连接状态独立显示。移动数据、Wi-Fi 使用同一个 HTTPS 远程入口，切网时主动重新检查，断网保留可见内容并明确标为离线。
- 成功配对并通过服务器认证后，将设备访问凭据用 Android Keystore 中不可导出的 AES-GCM 密钥加密保存。只保存设备接口所需凭据与蓝牙地址，不保存录音、管理员密码或浏览器会话；禁用系统备份。设备停用或凭据轮换仍由服务器拒绝访问。
- 蓝牙断开后手机继续同步；重开 App 可恢复已有认证。空闲约 6 秒刷新、处理中约 2 秒检查；展开的任务详情跟随刷新，包含电脑网页新增的会话消息及报告记录。手机和网页以服务端数据为准；长消息显示明确的全文查看提示。
- 暂时仍用 Quick Tunnel。电脑或通道重启可能改变域名，不能承诺手机在外时从已经失效的旧地址自行找到新地址。固定入口没有启用。
- 电脑端后台连接助手及其开机启动项已移除，启动语音服务不会再运行 ADB 地址同步。地址变化可在手机“服务器连接设置”更新；没有变化时自动重连，无需同一局域网。

App 1.2.2 增加独立启动图标：蓝底、白色书页和浅青语音波形，包含安卓自适应遮罩、单色主题层及五种密度的回退资源。设计源图与生成提示词在 `design/`；构建脚本用官方 aapt2 编译资源，沿用既有应用签名，更新安装保留原任务和配对。

原生 Java App，Android 13 及以上；当前实机为 iQOO Neo8 / OriginOS 6 / Android 16。
手机负责网络中转，不需要热点、Root 或手机端语音模型。

## 使用

1. 开启手机蓝牙与移动数据，打开「智库随行」。
2. 点击「配对 / 连接开发板」，在列表中选择 KB Note4。列表支持不同开发板，当前一次连接一台。
3. 首次按系统提示配对，输入板端六位码；无需勾选通讯录权限。后续配对记录会保留。
4. App 显示「已连接 · 热点可以关闭」后，即可关闭热点。界面显示型号、固件、屏幕、录音规格、蓝牙地址、设备名称、编号与目标会话。
5. 按住开发板说话、松手发送，快速双击取消。仍为单次完整转写，没有恢复流式输入。
6. App 收起后由带常驻通知的 connectedDevice 前台服务中转，断开后重连。OriginOS 若限制后台运行，可从「后台运行设置」进入系统应用详情进行调整。长时间锁屏稳定性与电池消耗仍需实际观察。

## 任务中心与设备连接（1.2.0）

- 两个独立页面：任务中心用于处理工作，设备连接用于配对、查看开发板信息和中转状态。任务列表默认收起，点选后展开最近六条语音、回复及操作按钮。
- **一个任务对应一个知识库会话**。首次录音创建当前任务，后续语音继续补充同一任务；点击「＋ 新建任务」才切换到另一个任务。「继续这个任务」可返回原任务。历史固定会话保留原有记录，不自动拆分。
- 不同任务最多四项并行，同一任务的语音按到达顺序处理、沿用上下文。最多十二条未完成录音，超过限制的录音由板端保留并等待发送。原有每分钟提交上限仍生效。录音被服务器接收后即可继续录下一条，无需等待 AI 回复；上传过程中仍需等本条发送完成。
- 录音开始时固定任务选择版本。手机或开发板在录音中切换任务，不会把已开始的录音发错会话；过期或已删除目标明确拒绝，不自动另建任务。
- 板端长按下键约 0.8 秒打开任务列表，短按上下键移动、短按正面确认；再次长按下键返回。列表首项为「新建任务」。手机任务选择和板端选择同步，屏幕显示当前任务编号。
- 重命名立即更新同一个知识库会话并留审计。删除走既有会话删除的一次确认和一次性凭据，取消确认保留任务；确认后同步移除会话、消息和设备端可访问的语音内容。已入库资料、已生成文档、受控操作审计保留。处理中任务不可删除。
- 手机仅能管理这台已配对设备所关联的任务会话；设备凭据仍不能调用通用管理接口，也不能据此删除知识库或入库资料。

## 构建和验证

从项目根目录运行：

```powershell
.venv/Scripts/python.exe scripts/build_android_relay.py --endpoint-file secrets/note4-current-endpoint.json
adb install -r artifacts/android-relay/KnowledgeBase-Relay.apk
.venv/Scripts/python.exe scripts/test_android_relay.py
```

使用本机官方 Android SDK 36、JDK 21，无 Gradle 和在线第三方依赖。可用 `--sdk`、`--jdk` 指定路径。
产物：`artifacts/android-relay/KnowledgeBase-Relay.apk`。测试为独立 APK，不访问网络或 AI；完成后可以移除 `cn.knowledgebase.relay.tests`。
签名文件位于被忽略的 `secrets/android-relay/`，须保留以便原位更新，不得提交。
可选 endpoint 文件只将**公开 HTTPS 远程入口地址**写入 APK，不含令牌、热点参数或录音。不传时使用开发板提供的地址。
Quick Tunnel 在电脑重启后可能换域名；可在 App 的「服务器连接设置」更新，无须重刷设备凭据。固定远程地址仍是后续部署事项。

## 传输与数据

- 开发板 → 加密 BLE → 手机 App → HTTPS → 电脑 Docker → ASR → AI 会话；回复与屏幕帧沿原路返回。这里使用自定义 BLE GATT 中转，不依赖传统蓝牙 PAN。
- 配对要求带认证的 LE Secure Connections；未认证链路不发送令牌、录音或回复。HTTPS 使用系统证书和域名校验，禁止明文与跳转。
- 手机不申请麦克风权限、不自行录音、不保存音频重放队列。1.3.0 起，成功认证的配对凭据加密保存在本机，以便脱离开发板仍能同步；令牌不写入明文配置、日志或 APK。
- 只代理指定的设备接口，不能转发网页管理或任意删除接口。主请求与取消请求独立；既有的唯一录音 UUID、取消墓碑和 AI 开始闸门继续生效。
- GATT 属性值上限 512 字节。7 字节帧头后，有效载荷为 `min(MTU - 3, 512) - 7`，MTU 517 时为 505 字节。不能直接发送 514 字节属性值；真机 20 项协议测试覆盖这个闪退回归。
- 请求元数据最多 4,096 字节、音频最多 2,000,044 字节、响应最多 120,000 字节；组装数量、顺序、偏移、总长度与 SHA-256 均受校验。实际要求 MTU 至少 247。
- HTTPS 中转时持有有时限的唤醒锁；蓝牙空闲约 15 秒后请求平衡连接优先级，传输时恢复较高优先级。尚未测量具体耗电改善比例。
- 未被服务端确认的录音由板端内存保留，断电会丢失；服务器接收后由持久任务处理。原始录音不作为知识库资料入库，终态超过一小时清理，会话保留转写文字与回复。

## 协议

App 1.2.1 配合固件 2.3.2 增加录音传输收讫确认：设备信息声明 `upload_ack: true` 时，手机对连续校验通过的元数据、录音分片每八片（或该段末尾）回复 type 12，头部 offset 为实际累计字节数，载荷一字节为原分片 type 2/3。type 13 立即拒绝错误传输。板端收到确认后才继续下一批；无确认最多等待八秒，终止该次蓝牙传输，再通过原 UUID 查询是否已经被知识库接收。新 App 可兼容未声明此能力的旧固件；固件 2.3.2 需使用 App 1.2.1。

接收回调、断开清理和重连在同一手机消息线程处理，旧连接排队回调不会进入新连接；断开时清空分片缓冲。错误诊断只记录帧类型、编号、偏移和长度，不记录音频、转写或凭据。真机 33 项协议检查覆盖连续偏移、八片窗口、末片、缺片拒绝和重连空缓冲；未完整传输的录音不提交知识库。它不是一条网页对话，失败提示不会再要求用户去网页寻找不存在的记录。

服务 UUID：`b04e0001-7a31-4aa4-9b8f-278ba019f604`。0002 为有响应写入、0003 为通知、0004 为加密设备信息读取。
帧头：类型 u8、请求 ID u16 LE、偏移或长度 u32 LE。1/2/3/4：请求开始/元数据/正文/结束；5/6/7：响应头/正文/结束；8：手机校时并确认就绪；10：放弃未完成传输。连接代次阻止旧连接响应写入新连接。
