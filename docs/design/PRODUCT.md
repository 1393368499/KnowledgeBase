# 智库

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

资料使用者在浏览器里上传、检索、核对与引用内部资料。知识库管理员管理资料范围、索引和运行状态。设备使用者配置语音设备的会话与检索范围。

## Product Purpose

从权限允许的资料中找到依据，在会话中查证或撰写可编辑、可预览和可导出的文档。

## Operating Context

登录后的工作区经常在会话、文件、搜索、模板、信息库、添加记录、运行控制、系统配置、设备和使用说明之间切换。项目支持 Docker 部署。模型可用性由实际服务状态决定。

## Capabilities and Constraints

- 保留现有网页路由、账号权限、接口、受控确认、文件和会话深链、后台进度与失败恢复。
- 保留资料上传和目录扫描、筛选与原件预览、搜索反馈、文档来源和模板、编辑与全部导出格式。
- 保留设备配对和远程地址设置、模型探测、运行审计与任务入口。状态来自服务端。
- 中文界面须适合手机、桌面与键盘操作。视觉方向由本次重构确定。
