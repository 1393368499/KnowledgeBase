# 仅删除需要确认

已部署至本地 Docker 的 web、worker、scheduler 与 voice-worker。

- 删除资料、删除信息库沿用三次独立确认与末次名称核对；删除个人会话沿用一次确认。
- reset_demo_data 会清除演示库业务资料，按删除处理，继续要求确认。
- 其它已开放操作参数完整且权限校验通过后直接执行，包括查询、创建库、资料性质修改、文档生成/导出和索引重建。停用的归档能力没有重新开放。
- 非删除操作不签发确认凭据，人工确认次数为零；审计、目标身份核验、执行期权限复核、执行窗口、CAS 与原件不可变规则仍然生效。
- 文档生成仍须指定至少一份参考文件；上传仍须选择文件。缺少必要输入时提示补齐，不生成待确认卡。
- 同轮模型重复提出相同写入/生成调用只执行一次，并将真实结果反馈给模型。
- 共用网页控件直接接收已执行结果，避免再弹框或再次调用执行接口。新文档仍可打开文档栏，上传仍可打开文件选择入口。
- 历史非删除待办不再作为确认卡显示；没有在升级或页面读取时自动执行历史请求，操作记录保留。
- 语音入口使用同一后端策略；删除仍需在网页完成确认，设备不持有删除确认凭据。

验证：SQLite 281 项通过、1 项环境相关跳过；PostgreSQL 142 项通过。浏览器实际调用查询操作，只有一次提案请求且无确认框；删除界面用模拟 API 验证三次独立弹框与名称输入，没有在生产库执行测试删除。真实删除权限与确认流程由隔离数据库回归覆盖。

历史确认、模板/来源编辑与执行阶段测试使用显式历史记录或执行前暂停夹具；新策略测试直接调用正式服务。证据位于忽略目录 artifacts/delete-only-*。
